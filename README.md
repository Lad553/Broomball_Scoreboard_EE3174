The Broomball Scoreboard is be capable of tracking game time, penalties, timeouts, and the score. There are several different pages that the screen is able to go through. The main page can display all the information. There is a second page to add penalty time, and a third to indicate that a team timeout or natural break is in progress. There can also be some hardware included to make to scoreboard easier to quickly operate: one button per team to increment the score, and one button to start/stop the game clock. The buttons are for ease of use while wearing thick gloves, but there is also an option to change the score on the screen in case there's a misinput. There can also be an LED and buzzer to provide a visual and audio indication when the game clock runs out.
